# Proyectos de Vue 3

Este repositorio contiene varios proyectos y ejemplos desarrollados durante el aprendizaje de Vue 3.

## Proyectos

- [vue3-app](vue3-app/README.md): Proyecto principal con Vue 3, Vite, Pinia y TypeScript.

## ¿Cómo agregar más proyectos?

1. Crea una nueva carpeta para tu proyecto dentro de este repositorio.
2. Agrega un archivo README.md dentro de la carpeta del nuevo proyecto.
3. Enlaza el nuevo README aquí, por ejemplo:
   - [nombre-del-proyecto](nombre-del-proyecto/README.md)

Así tendrás un índice centralizado para acceder rápidamente a la documentación de cada proyecto.
